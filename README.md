# Flutter & Dart Learning Repository

Welcome to my comprehensive repository for Flutter and Dart development! 

This repository serves as a centralized collection of my classwork, assignments, personal projects, and practice scripts created during my journey of learning mobile and web application development with Flutter and Dart. 

## 📂 Repository Structure

The repository is organized into several key areas:

### 🎓 Assignments
A progressive series of assignments demonstrating core concepts and full-stack development:
* **Assignment 1-3** (`vijaykota_4074_ass1`, `ass2`, `ass3`): Foundational Dart and Flutter concepts.
* **Assignment 4 - Books CRUD App** (`itm-flutter-assignment-4-books-crud-app`): A full-stack application for managing book records.
* **Assignment 5 - MCQ Exam Portal** (`vijaykota_4074_ass5`): A comprehensive exam portal with student and admin interfaces, featuring secure authentication, randomized questions, and automated result generation.

### 💻 Classwork & Mini-Projects
Practical implementations of specific features and integrations:
* **Authentication Flows** (`auth_app`, `auth_api`, `firebase_auth`): Implementations of user authentication using custom Node.js APIs and Firebase Auth.
* **Database Management** (`college_data_with_sqflite_database`): Local data persistence using the `sqflite` package.
* **CRUD Operations** (`employee_crud_app`, `employee_crud_api`): Full-stack Create, Read, Update, and Delete implementations.
* **Cloud Storage** (`flower_app_with_cloudinary_storage`): Image uploading and retrieval using Cloudinary.
* **UI & Navigation** (`profile_ui_with_navigation`, `showhide_app`, `stopwatch`): Focusing on responsive UI design, state management, and navigation routing.

### 📝 Dart Practice Scripts
* Various standalone Dart scripts (`practise.dart` to `practise11.dart`, `example.dart`) covering fundamental programming logic, OOP concepts, data structures, and algorithms in Dart.

## 🚀 Technologies Used
* **Frontend:** Flutter (Mobile/Web/Desktop), Dart
* **Backend:** Node.js, Express.js (for custom APIs)
* **Databases:** SQLite (local), Firebase (NoSQL), MongoDB
* **State Management:** Provider / SetState
* **Third-party Services:** Cloudinary (Storage), Firebase (Auth)

## 🛠️ How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/vijayKota2776/flutter.git
   ```
2. Navigate to the specific project directory you wish to run.
3. Fetch dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
*(Note: Some full-stack projects require starting the backend API separately. Refer to the specific project folders for more details.)*
