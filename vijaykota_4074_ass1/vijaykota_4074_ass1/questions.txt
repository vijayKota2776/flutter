# Dart 100 Practice Questions

## 1. Declare all primitive types in Dart
**Category:** Variable & Data type
**Description:** Create variables of type int, double, String, bool, and dynamic. Assign values and print using print(). Also show type inference with var and final.

## 2. Swap two numbers
**Category:** Operators
**Description:** Take two integers (a=10, b=20). Swap using a temporary variable, then again without temp (using arithmetic or bitwise XOR). Print before and after.

## 3. Largest of three numbers (ternary)
**Category:** Operators / Conditional
**Description:** Take three numbers. Use the ternary operator (? :) to find and print the largest.

## 4. Even or odd using bitwise
**Category:** Operators
**Description:** Input a number and check even/odd using bitwise AND (&) with 1. Print 'Even' or 'Odd'.

## 5. Arithmetic operations
**Category:** Operators
**Description:** Perform +, -, *, /, ~/ (integer division), and % on two integers. Print each result.

## 6. Increment / Decrement
**Category:** Operators
**Description:** Demonstrate prefix (++a) and postfix (a++) increment, and similarly decrement. Print values to see difference.

## 7. String comparison
**Category:** Operators / Data type
**Description:** Create two String objects with same content. Compare using == and .compareTo(). Print results.

## 8. Celsius to Fahrenheit
**Category:** Operators / Data type
**Description:** Take temperature in Celsius (double), convert to Fahrenheit using formula (C * 9/5) + 32. Print result.

## 9. Area of shapes using constants
**Category:** Variable & Data type
**Description:** Define constants (final) for PI. Compute area of circle (πr²), rectangle (l*w), triangle (0.5*b*h). Print.

## 10. Leap year using logical operators
**Category:** Operators / Conditional
**Description:** Input a year. Check if leap: divisible by 400 OR (divisible by 4 AND not divisible by 100). Use &&, ||, !.

## 11. Positive, negative or zero
**Category:** Conditional statements
**Description:** Read an integer. Use if-else-if to print whether positive, negative, or zero.

## 12. Day of week using switch
**Category:** Conditional statements
**Description:** Take a number 1-7. Use switch-case to print corresponding day (1=Monday...7=Sunday). Include default for invalid.

## 13. Grade calculation
**Category:** Conditional statements
**Description:** Input marks (0-100). Using if-else ladder assign grade: A (≥90), B (75-89), C (60-74), D (45-59), F (<45). Print grade.

## 14. Vowel or consonant using switch
**Category:** Conditional statements
**Description:** Read a character. Use switch-case to check if vowel (a,e,i,o,u - both cases). Print vowel/consonant.

## 15. Maximum of four numbers (nested if)
**Category:** Conditional statements
**Description:** Take four numbers. Use nested if-else to find and print the maximum.

## 16. Print 1 to 100
**Category:** Loop statements
**Description:** Use for loop to print numbers from 1 to 100.

## 17. Sum of natural numbers (while)

## 18. Multiplication table (do-while)

## 19. Fibonacci series (for loop)

## 20. Prime number check (for + break)

## 21. Factorial using for loop
